# E-Commerce Sales Analytics

## Project Overview
This project explores e-commerce sales data to uncover business insights, evaluate sales performance, understand customer purchasing behaviour, and identify product trends.

## Objectives
- Analyse overall sales and revenue performance.
- Identify top-performing products and categories.
- Examine customer purchasing behaviour.
- Evaluate monthly and seasonal sales trends.
- Identify opportunities to improve business performance.

## Tools and Technologies
- Microsoft Excel
- SQL
- Power BI
